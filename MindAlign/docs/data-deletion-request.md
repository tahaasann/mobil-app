# MindAlign — Veri Silme Talebi

Play Console **Data safety** ve kullanıcı hakları için resmi silme kanalı.

## Uygulama içi (önerilen)

1. MindAlign → **Profil** sekmesi
2. **Verileri sıfırla** → onayla
3. Kayıtlı hesapta: cihaz verisi + Firestore verisi + Firebase Auth hesabı silinir

## E-posta ile talep

Hesaba erişemiyorsanız veya web üzerinden talep etmek istiyorsanız:

- **E-posta:** `privacy@mindalign.app` *(yayın öncesi gerçek adresinizi buraya yazın)*
- **Konu:** `MindAlign Data Deletion Request`
- **İçerik:** Kayıtlı e-posta adresiniz + “Tüm verilerimi silin” onayı

## SLA

- Talep **30 gün içinde** işlenir (genelde 7 iş günü)
- Silinen veriler: habits, streaks, bookmarks, chat, profil, AI kullanım sayaçları, Firestore yedekleri, Firebase Auth hesabı

## Play Console formu

Data deletion URL olarak bu dosyanın GitHub/raw veya yayınladığınız statik site URL’sini girin:

`https://github.com/<org>/NewLifeApp/blob/main/MindAlign/docs/data-deletion-request.md`

*(Production’da kendi domain’inize taşıyın.)*
